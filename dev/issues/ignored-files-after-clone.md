# Arquivos ignorados só são copiados na segunda execução depois de um clone

Os arquivos ignorados de um repositório só são copiados a partir da segunda
execução, depois que ele é clonado em uma máquina.

Origem: `BACKLOG.md`, seção "Limitações conhecidas".

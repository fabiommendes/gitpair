# Merge de três vias das listas `repos` quando a configuração remota difere

Quando a configuração remota é diferente da local, o gitpair se recusa a
sobrescrevê-la e pede ao usuário que a copie à mão. Um merge de três vias das
listas `repos` eliminaria a maioria desses casos.

Origem: `BACKLOG.md`, seção "Limitações conhecidas".
